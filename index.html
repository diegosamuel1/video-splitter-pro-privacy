Política de Privacidade

Video Splitter Pro

1. Resumo

O Video Splitter Pro é um aplicativo para selecionar vídeos do dispositivo, dividir esses vídeos em clipes menores, salvar os clipes localmente e compartilhar os arquivos por meio dos aplicativos escolhidos pelo usuário.

O app foi projetado para processar os vídeos no próprio dispositivo. O desenvolvedor do Video Splitter Pro não vende dados pessoais e não usa os vídeos do usuário para publicidade.

2. Dados que o app acessa

Para funcionar, o app pode acessar vídeos selecionados pelo usuário, informações técnicas desses vídeos, como duração, tamanho, nome do arquivo e resolução, arquivos de clipes gerados pelo próprio app e configurações escolhidas pelo usuário, como qualidade padrão, modo de precisão e destino de salvamento.

Esses dados são usados para executar as funções do app: importar, cortar, salvar e compartilhar vídeos.

3. Vídeos e arquivos do usuário

Os vídeos escolhidos pelo usuário são processados localmente no dispositivo. O Video Splitter Pro não envia os vídeos para servidores do desenvolvedor para realizar o corte.

Quando o usuário escolhe compartilhar um clipe, o arquivo é enviado ao aplicativo escolhido pelo usuário, como WhatsApp, Instagram, Telegram, Facebook ou outro app instalado. A partir desse momento, o tratamento do arquivo fica sujeito às políticas de privacidade do aplicativo ou serviço escolhido pelo usuário.

Quando o usuário escolhe salvar os clipes, os arquivos são gravados no armazenamento local do aparelho, no destino configurado pelo usuário.

4. Dados coletados pelo desenvolvedor

O desenvolvedor do Video Splitter Pro não coleta, armazena ou vende dados pessoais do usuário por meio do app.

O app não solicita login, nome, e-mail, telefone, endereço, documentos pessoais ou dados de pagamento dentro do aplicativo.

5. Permissões utilizadas

O app pode solicitar ou utilizar permissões relacionadas a acesso a vídeos do dispositivo, leitura de mídia de vídeo, gravação de arquivos no armazenamento local quando exigido por versões antigas do Android, vibração/haptics e acesso à internet quando necessário para recursos técnicos da plataforma do app.

As permissões são usadas apenas para permitir as funções do app. O usuário pode gerenciar permissões nas configurações do Android.

6. Compartilhamento de dados

O Video Splitter Pro não compartilha dados pessoais com terceiros por iniciativa própria.

O compartilhamento de clipes ocorre somente quando o usuário aciona uma opção de compartilhamento. Nesse caso, o arquivo selecionado é entregue ao aplicativo ou serviço escolhido pelo usuário.

7. Retenção e exclusão

Os clipes gerados permanecem no dispositivo do usuário até que sejam apagados pelo próprio usuário ou removidos pelas configurações e ações do app.

O usuário pode limpar cortes anteriores dentro do app e também pode excluir arquivos salvos usando a galeria ou gerenciador de arquivos do dispositivo.

8. Crianças

O Video Splitter Pro não é direcionado especificamente a crianças e não solicita dados pessoais de crianças. Caso o app seja usado por menores de idade, o uso deve ocorrer com acompanhamento de um responsável.

9. Segurança

O app busca reduzir o acesso a dados ao necessário para suas funções principais. Como os vídeos são processados localmente, o usuário mantém controle sobre seus arquivos no próprio dispositivo.

Nenhum sistema é completamente imune a falhas. Por isso, recomenda-se manter o app e o sistema Android atualizados.

10. Alterações nesta política

Esta Política de Privacidade pode ser atualizada para refletir mudanças no app, exigências legais ou requisitos da Google Play. Quando houver alterações relevantes, a data de atualização será modificada.
